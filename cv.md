## Proyectos

### Dashboard Analítico Dual

Aplicación web de analítica con REST API | Completado

Sistema de analíticas para restaurante: un cliente en Godot envía datos mediante REST API a un dashboard web que muestra tiempos de preparación y entrega, ingresos por hora, cancelaciones y horas pico.

- Problema: Un restaurante genera datos en cada pedido, pero sin verlos juntos no sabe dónde pierde tiempo ni dinero.
- Solución: Un cliente en Godot envía cada evento por REST API a un dashboard web con tiempos de preparación y entrega, ingresos por hora, cancelaciones y horas pico.
- Mi rol: Desarrollo del cliente en Godot, la integración por REST API y el dashboard web.
- Tecnologías: REST API, desarrollo web, analítica de datos, Godot

### CultivAR

App móvil Android con realidad aumentada | Completado, 2023

Realidad aumentada que asiste en el cuidado de plantas de tomate: detecta la planta y muestra en pantalla información de cuidado en contexto.

- Problema: Cuidar un cultivo de tomate exige saber qué necesita cada planta en el momento, y esa información rara vez está a la mano en el campo.
- Solución: Una app Android que detecta la planta con la cámara y coloca sobre ella la información de cuidado en realidad aumentada.
- Mi rol: Desarrollador principal: lideré el proyecto de principio a fin, diseñé la interfaz y la función de realidad aumentada, y tomé las decisiones técnicas.
