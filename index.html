Aplicación web de analítica con REST API

Dashboard Analítico Dual

Los datos del restaurante, en una sola pantalla.

Problema
Un restaurante genera datos en cada pedido, pero sin verlos juntos no sabe dónde pierde tiempo ni dinero.
Solución
Un cliente en Godot envía cada evento por REST API a un dashboard web con tiempos de preparación y entrega, ingresos por hora, cancelaciones y horas pico.
Mi rol
Desarrollo del cliente en Godot, la integración por REST API y el dashboard web.
Tecnologías
REST API, desarrollo web, analítica de datos, Godot

Completado

CultivAR

Del campo a tu pantalla.

Problema
Cuidar un cultivo de tomate exige saber qué necesita cada planta en el momento, y esa información rara vez está a la mano en el campo.
Solución
Una app Android que detecta la planta con la cámara y coloca sobre ella la información de cuidado en realidad aumentada.
Mi rol
Desarrollador principal: lideré el proyecto de principio a fin, diseñé la interfaz y la función de realidad aumentada, y tomé las decisiones técnicas.
Tecnologías
C#, Unity, ARCore, Android
Estado
Completado, 2023
